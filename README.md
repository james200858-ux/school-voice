# 🎤 School Voice — 학생 의견 기반 학교 개선 플랫폼

학생들이 학교생활에서 느끼는 불편 사항을 자유롭게 등록하고,
다른 학생들이 확인하고 공감할 수 있는 웹 애플리케이션 프로토타입입니다.

> 본 프로젝트는 실제 서비스 운영이 아닌, **아이디어 시연을 위한 MVP(최소 기능 제품)**로 제작되었습니다.

---

## 📌 프로젝트 소개

학교에는 시설, 급식, 학사 운영 등 다양한 영역에서 학생들이 느끼는 불편함이 있지만,
이를 모으고 공유할 창구가 마땅치 않은 경우가 많습니다.

**School Voice**는 이러한 문제의식에서 출발해,
누구나 쉽게 의견을 남기고 공감할 수 있는 최소한의 구조를 구현한 프로토타입입니다.

---

## ✨ 주요 기능

| 기능 | 설명 |
|---|---|
| 의견 목록 조회 | 등록된 의견을 카드 형태로 최신순 표시 |
| 의견 등록 | 제목, 내용, 카테고리를 입력해 새 의견 등록 |
| 의견 상세 보기 | 개별 의견의 전체 내용 확인 |
| 공감(좋아요) | 로그인 없이 버튼 클릭으로 공감 가능 |
| 검색 | 제목 키워드로 의견 검색 |
| 통계 | 카테고리별 게시글 수를 막대그래프로 시각화 |

---

## 🛠 기술 스택

- **Backend**: Python, Flask
- **Database**: SQLite
- **Frontend**: HTML, CSS, JavaScript (Vanilla)
- **Chart**: Chart.js (CDN)

React, Next.js 등 무거운 프레임워크 없이,
빠른 프로토타이핑에 집중하기 위해 최소한의 기술 스택만 사용했습니다.

## 🚀 실행 방법

1. 저장소 클론
```
git clone https://github.com/james200858-ux/school-voice.git
cd school-voice
```

2. 필요한 패키지 설치
```
pip install -r requirements.txt
```

3. 서버 실행
```
python app.py
```

실행 후 브라우저에서 `http://localhost:5000` 접속
